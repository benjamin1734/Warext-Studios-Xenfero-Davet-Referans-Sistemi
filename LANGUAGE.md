# Language support / Dil desteği

Referral System uses XenForo's native phrase/language system. Import `languages/Turkish.xml` or `languages/English.xml` into the corresponding XenForo language (or a child language). The add-on follows each visitor's selected XenForo language.

User-generated reward titles/descriptions or staff-entered reasons remain content and are not automatically translated.

Yeni kullanıcıya görünen sabit metinler phrase kullanılmadan template/PHP/JS içine eklenmemelidir.
